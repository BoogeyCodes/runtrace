Compare agent runs

Paste several AI coding-agent transcripts — in whatever shape they arrived — and runtrace normalises each into one schema and lays them side by side: metrics, a one-line summary, and which runs touched the same files.

Different field names are fine — tool/type/action, cmd/input, additions/deletions…
